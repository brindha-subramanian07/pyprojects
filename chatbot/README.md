🤖 Console Chatbot & Student Marks Analyzer

A beginner-friendly Python project that combines a keyword-based console chatbot with a student marks analysis system. It demonstrates the use of Python dictionaries, lists, functions, loops, conditional statements, and basic data processing.

📌 About the Project

This project consists of two main functionalities:

1. Console Chatbot: A simple chatbot that interacts with users by matching keywords with predefined responses. It continues the conversation until the user types "bye" and stores the entire conversation in a list of dictionaries.

2. Student Marks Analyzer: A function-based program that analyzes a list of student marks and calculates the average, highest, and lowest marks.

✨ Features

🤖 Console Chatbot

- Interactive command-line conversation.
- Keyword-based response matching using a dictionary.
- Predefined replies for common inputs.
- Continuous conversation until the user types "bye".
- Conversation history stored as a list of dictionaries.
- Displays the complete conversation history.

📊 Student Marks Analyzer

- Accepts marks for multiple students.
- Stores marks using a Python list.
- Calculates average marks.
- Identifies the highest mark.
- Identifies the lowest mark.
- Returns all three results using a function.

🛠️ Technologies Used

- Programming Language: Python 3
- Data Structures: Lists and Dictionaries
- Concepts: Functions, Loops, Conditional Statements, String Handling
- Interface: Command-Line Interface (CLI)
