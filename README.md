🧮 Mini Scientific Calculator

A Python-based scientific calculator that performs basic arithmetic and advanced mathematical operations through a simple command-line interface. It also includes a personalized greeting feature to welcome users.

📌 About the Project

This project is developed using Python to perform different mathematical calculations. It provides a menu-driven interface where users can select an operation and get the calculated result.

The calculator uses Python's built-in Math module for scientific operations and exception handling for invalid inputs.

✨ Features

- Personalized greeting using the user's name.
- Addition of two numbers.
- Subtraction of two numbers.
- Multiplication of two numbers.
- Division with zero-division validation.
- Power calculation.
- Square root calculation.
- Sine calculation.
- Cosine calculation.
- Tangent calculation.
- Logarithmic calculation.
- Input validation and error handling.

🛠️ Technologies Used

- Python 3
- Math Module
- Exception Handling
- Visual Studio Code
